# 🎵 Music Streaming Analytics Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **Music Streaming Analytics Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes music streaming data to identify trends in **tracks, artists, songs, streaming performance, yearly growth, and music characteristics**.

It provides an easy-to-understand visual overview of streaming performance and helps users explore popular tracks and artists.

---

## 🎯 Objectives

- Analyze overall music streaming performance
- Identify the most streamed tracks
- Analyze artists based on the number of tracks
- Track yearly streaming trends
- Understand song distribution by mode
- Identify the most streamed artist and track
- Provide interactive filtering for monthly analysis

---

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **Data Visualization**
- **Data Analysis**

---

## 📌 Dashboard Features

### 🔹 KPI Cards

The dashboard includes key performance indicators for:

- **Total Tracks**
- **Total Artists**
- **Total Songs**
- **Total Streams**

Example dashboard values:

| KPI | Value |
|---|---:|
| Total Tracks | 79 |
| Total Artists | 69 |
| Total Songs | 80 |
| Total Streams | 44B |

---

### 🔹 Top 10 Streaming Tracks

A bar chart displays the **Top 10 tracks based on total streams**.

Some of the highly streamed tracks include:

- Blinding Lights
- Someone You Loved
- Watermelon Sugar
- Love Yourself
- Die For You
- Before You Go
- Cold Heart - PNAU Remix
- Rolling in the Deep

---

### 🔹 Top Artists by Total Tracks

A donut chart shows the distribution of artists based on their total number of tracks.

The visualization provides a quick comparison of artist contribution within the dataset.

---

### 🔹 Streaming Details Table

The dashboard contains a detailed table showing:

- Track Name
- Artist Name
- Total Streams

This allows users to quickly compare individual track performance.

---

### 🔹 Song Distribution by Mode

A donut chart analyzes songs based on musical mode:

- **Major – 67.5%**
- **Minor – 32.5%**

---

### 🔹 Yearly Streams Analysis

A line/area chart visualizes **total streams across different years**.

This helps identify changes and growth patterns in music streaming over time.

---

### 🔹 Most Streamed Track

The dashboard highlights the most streamed track along with:

- Artist Name
- Track Name
- Release Date
- Total Streams

---

### 🔹 Interactive Month Filter

A month slicer allows users to filter the dashboard based on the selected month.

This makes the dashboard interactive and allows users to explore specific periods.

---

## 📈 Key Insights

The dashboard can be used to identify:

- Tracks with the highest streaming volume
- Artists with a larger number of tracks
- Changes in streaming activity over the years
- Distribution of songs between Major and Minor modes
- Overall streaming performance
- Individual track and artist performance
